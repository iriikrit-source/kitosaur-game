# Kitosaur 🦖

A platformer desktop game built with Unity.

## 📖 Gameplay & Objective
Save your eggs before it's too late! Navigate across treacherous terrain by timing your jumps across cacti, bouncing on bubbles for a double jump, and striking down incoming pterodactyls to reach the goal.

## 🎮 How to Play
1. Go to the **[Releases](../../releases)** section.
2. Download `Kitosaur-v1.0-Windows.zip`.
3. Extract the folder and launch `Kitosaur.exe`.

## 🕹️ Controls
* **Movement:** WASD / Arrow Keys
* **Jump:** Spacebar
* **Double Jump:** Mid-air contact with bubbles
* **Attack:** A Button / Key

## 🛠️ Built With
* Unity Engine
* C#
